One line, one breath, one very questionable diagnosis: an all-night symptom-Googling session ends with the sender either dying or a hypochondriac — and either way, they're not coming in. It's half believable because everyone has done exactly this at 3 a.m., it's fresh because the excuse isn't a fake illness but a fake *diagnosis process*, and the laugh lands mid-line, long before the shrug at the end.

## Run it

```sh
python3 main.py
```

This writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`): exactly one line, under 200 characters, no trailing newline.
